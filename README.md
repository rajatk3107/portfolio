# Developer Portfolio

A modern, minimal portfolio website for a backend-focused web developer built with Vue 3 and Tailwind CSS.

## Stack

- Vue 3 with Composition API
- Tailwind CSS
- Vite

## Project Structure

## Run Locally

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Build for production:

```bash
npm run build
```

4. Preview the production build:

```bash
npm run preview
```

## Notes

- Replace placeholder text such as name, company names, links, and resume content with your actual details.
- The contact form is UI-only and does not submit anywhere yet.
- The hero currently uses a static image from `public/man.png`.
